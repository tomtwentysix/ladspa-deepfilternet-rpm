# ladspa-deepfilternet

RPM packaging of [DeepFilterNet](https://github.com/Rikorose/DeepFilterNet)'s LADSPA noise
suppression plugin, built in the [solartw/skitz-effects](https://copr.fedorainfracloud.org/coprs/solartw/skitz-effects/)
COPR for Skitz Effects' Deep Noise Remover.

A weekly workflow moves the spec to DeepFilterNet's latest release, and COPR rebuilds on push.
